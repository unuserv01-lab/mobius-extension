### Build issues fixed during this run
1. `AIRouter.ts` — TS narrowing of the `OnDeviceAI` result union lost after a bare block;
   fixed by capturing `nanoError` once.
2. `OnDeviceAI.ts` — `getGenerativeModel` params cast corrected to the SDK's param type.
3. `vite.config.ts` — `defineConfig` does not accept an array of configs; replaced with
   `scripts/build.mjs` calling Vite's `build()` API three times.
4. `publicDir` is a top-level Vite option in Vite 6, not under `build`.
5. **Bundler constant-folding**: placeholder config literals were folded away, deleting the
   Firebase init / App Check debug-token paths from the bundle. Fixed by parsing the
   config from `JSON.parse` at runtime (verified: placeholders + debug-token code now
   present in `dist/background.js`).
